# docs/

Documentation for the drone-agent project.

- `docs/agents/` — Agent-facing documentation. These files are referenced by AGENTS.md and are meant to be read by LLM agents working on the project.
- `docs/adr/` — Architecture Decision Records (ADRs). The canonical, project-owned decision history (`NNN-slug.md`, 3-digit, sequential). The project wiki's `decisions/` pages are pointer stubs that redirect here.
